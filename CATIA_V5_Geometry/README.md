# CATIA V5 Slider-Crank Geometry

This folder contains a CATIA V5 geometry-only assembly with the ground, crank, connecting rod and slider as separate CATParts, plus their CATProduct.

Keep all five CATIA files together when opening the CATProduct so CATIA can find its linked parts. The product does not contain solved DMU Kinematics joints; the repository's motion animation and results remain analytical.
